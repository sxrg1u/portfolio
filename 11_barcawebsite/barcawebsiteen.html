Barça Website

2026 · School Project · IMS-T Switzerland

C#ASP.NET Core MVCHTMLCSS

The Goal

An FC Barcelona fan website built with ASP.NET Core MVC. I wanted to learn how controllers, views and models work together and how a C# application turns into a website.

Structure

The home page shows the 2026/27 season and the three most recent trophies. There are also pages for the squad, every trophy since 2010 and your favourite players. With login and registration you can create an account.

What I Built

  • One controller with an action per page
  • Razor views with a shared layout
  • Login and registration with GET and POST actions
  • Showing error messages through the ViewBag
  • A custom 404 page with status code pages
  • A design of my own in Barça's colours
