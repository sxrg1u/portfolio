Snake Game

2026 · School Project · IMS-T Switzerland

C#Win-Forms.NETRawGameController API

How the Game Works

Snake in C# with Windows Forms. The snake eats apples and grows longer with each one. A collision ends the round, and you can restart right away. You can play with the keyboard or with a game controller.

The Assignment

At school we had to program a small game of our own. It had to use events, timers and objects, have a clean structure and run without crashing.

New to Me

  • Forms and controls in Windows Forms
  • Timers and events to drive the game
  • Using classes and objects in a project of my own
  • Detecting collisions
  • Connecting a game controller through the RawGameController API
