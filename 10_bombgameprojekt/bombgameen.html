Bomb Game

2026 · Personal Project · C#

C#Win-Forms.NET

The Goal

Bomb Game works like Minesweeper and runs on C# and Windows Forms. You have to reveal every safe tile without hitting a bomb. Each safe click earns points, and a bomb ends the round.

How a Round Plays

You click tiles on a grid. A safe tile turns green. Hit a bomb and the screen flashes while particles fly. A timer tracks your time, and the game saves your best score locally. Open every safe tile and you win.

What I Built

  • Generating the board from WinForms panels at runtime
  • Placing bombs at random in a 2D array
  • Running the game flow with timers
  • Handling clicks on the grid
  • Explosion with a screen flash
  • A particle system of my own in WinForms
  • Writing the highscore to a file with File I/O
